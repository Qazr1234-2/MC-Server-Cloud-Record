填写 Gist ID 后即可读取客户端上传的服务器连接记录。

  1. 运行 client\build\McServerUploader.exe，首次运行会自动创建私密 Gist，并把 ID 写回 config.json。
  2. 打开 config.json 复制其中的 gistId。
  3. 粘贴到上方输入框并点击“保存并加载”。
客户端原理：Toolhelp 进程枚举 → GetExtendedTcpTable 读取 TCP 连接表 → 过滤 ESTABLISHED 连接 → GitHub Gist API 备份。全程只读网络连接信息，无需管理员权限。
